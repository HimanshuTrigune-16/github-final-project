# Simple Interest Calculator

## 📌 Description
This project is a simple interest calculator that computes the interest based on principal, rate of interest, and time period.

## 🧮 Formula Used
Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time (in years)

## 💻 Example
If:
P = 1000  
R = 5%  
T = 2 years  

Simple Interest = (1000 × 5 × 2) / 100 = 100
